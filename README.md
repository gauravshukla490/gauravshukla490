### Featured Projects

#### 💸 [Splitly](https://github.com/gauravshukla490/splitly) — Expense splitting app
Splitwise-style full-stack app for shared expenses in groups and one-on-one.
- Equal, percentage and exact splits with server-side validation; balances derived from a ledger with pairwise debt netting
- OTP-verified signup, bcrypt hashing, JWT access + refresh tokens in HTTP-only `SameSite=strict` cookies
- Multi-table writes wrapped in database transactions; money stored as `NUMERIC` to avoid float errors
- 🚧 Next: natural-language expense entry with Gemini (*"I paid 1200 for dinner with Rahul and Amit"* → pre-filled expense)

`React` `TypeScript` `Express` `PostgreSQL` `Drizzle ORM` `Tailwind` `Docker`

#### 🔍 [CodeLens](https://github.com/gauravshukla490/codeLens) — Code review platform *(in progress)*
- GitHub OAuth sign-in with Better Auth, protected dashboard routes
- Prisma 7 with the Postgres driver adapter on serverless NeonDB

`Next.js` `TypeScript` `Better Auth` `Prisma` `NeonDB` `TanStack Query` `shadcn/ui` `RAG`
